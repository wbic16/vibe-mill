## Software Life Cycle

Software entities are clones produced at scale. We design, implement, build, and then run projects. A program may run for an indeterminate amount of time, resulting in either natural termination or a crash.

1. Design
2. Implement
3. Build
4. Run
5. Terminate/Crash

## Software Growth Cycle

The software development (growth) cycle is slightly different, and focuses on the development process itself.

1. Requirements
2. Tests
3. Code
4. Verification
5. Competition
6. Reward
